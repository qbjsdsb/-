# V1 UX / Data QA Gate

每次明显改动 UI、路由、数据模型或同步流程后，至少检查以下项目。

## 视口

- 360×800：无横向溢出；底部导航可用；所有主要点击目标 ≥ 44px
- 768×1024：布局不拥挤；筛选可以自然收纳
- 1440×900：桌面侧栏、搜索和主内容层级清楚
- 1920×1080：内容不会无限拉宽

## 核心 Journey

1. 首页 → 全站搜索 → 打开英雄
2. 首页 → 资料库 → 筛选英雄 → 打开详情
3. 英雄详情 → 相关装备 / 天赋 / 阵容
4. 阵容列表 → 阵容详情 → 成员英雄详情
5. 首页 → 当前版本 → 版本页
6. 手机：首页 → 资料 → 阵容 → 更多

## 状态

- 图片 404：隐藏破图，保留 fallback
- 搜索无结果：提供下一步
- 资料加载失败：显示可重试信息
- live 数量漂移：版本页明确显示待同步
- 空关系：不要伪造推荐，显示“样本暂无记录”

## 数据

运行：

    python3 scripts/validate_data.py
    node --check assets/app.js

必须通过硬 Gate。

## 设计

- 一个视口只存在一个明确主视觉
- 不新增无意义 Card
- 不用颜色装饰无语义内容
- 不把技术 JSON 放在正文前部
- 新功能先判断归属：资料库 / 阵容 / 版本 / 工具
