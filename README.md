# 万象图鉴 · 王者万象棋资料库

这是一个面向《王者万象棋》玩家的非官方静态资料站。

## v0.1 目标
- 英雄、棋手、装备、天赋、效果牌、阵容、机制与资讯统一搜索
- 数据来源与版本日期公开
- 当前版本 v1.3.1（2026-09-24）重点改动单独校验
- 手机 / 桌面双端
- 纯静态，无数据库、无付费服务

## 数据策略
基础结构化数据来自公开的万象棋谱 JSON 数据源，并保留来源说明。由于其结构化快照日期为 2026-09-16，而 2026-09-25 在线资料已显示 85 英雄 / 79 装备 / 255 天赋 / 99 效果牌 / 21 棋手，站点会明确显示版本差异，而不是把旧快照伪装成最新数据。

## 当前状态
本分支是第一版可运行原型。合并后可用 GitHub Pages 发布仓库根目录。

> 非官方玩家资料工具，与腾讯游戏无隶属关系。
